# GameCard03832 — PANG GOLF ⛳

เกมกอล์ฟ 3D แนวแฟนตาซีสไตล์ **ปังย่า (Pangya)** สร้างด้วย Unity
โลกทั้งหมด (สนาม ต้นไม้ น้ำ ท้องฟ้า เสียง) **สร้างด้วยโค้ดตอนรันเกม** ไม่ต้องใช้ไฟล์โมเดล รูป หรือเสียงจากภายนอก

## วิธีเปิดเกม

1. ติดตั้ง **Unity 2022.3 LTS** หรือ **Unity 6** ผ่าน Unity Hub
2. ใน Unity Hub กด **Add → Add project from disk** แล้วเลือกโฟลเดอร์นี้
3. เปิดโปรเจกต์ (ครั้งแรกรอ import สักครู่)
   - สคริปต์จะตั้งค่าโปรเจกต์อัตโนมัติ (Linear color, shader ที่จำเป็น และสร้างฉาก `Assets/PangGolf/Scenes/PangGolf.unity`)
   - ถ้าไม่ขึ้น ให้ใช้เมนู **PangGolf → Setup Project**
4. กด **Play** ▶ ได้เลย (กด Play จากฉากไหนก็ได้ เกมจะเริ่มเอง)

> ถ้าใช้ Unity 6 แล้วปุ่มกดไม่ตอบสนอง: ไปที่ *Edit → Project Settings → Player → Active Input Handling* แล้วเลือก **Both**

## ตัวละคร

หลังหน้า Title จะเข้าหน้า **เลือกตัวละคร** (กด ← → เลือก, ENTER ยืนยัน) เกมจะจำตัวที่เลือกไว้ครั้งถัดไป
ค่าพลังแต่ละอย่าง (1–5) มีผลกับการตีจริง:

| ตัวละคร | สไตล์ | Power | Control | Accuracy | Spin | Curve |
|---|---|:-:|:-:|:-:|:-:|:-:|
| **Kai** | All-Rounder สมดุลทุกด้าน เหมาะกับมือใหม่ | 3 | 3 | 3 | 3 | 3 |
| **Momo** | Spin Princess ลูกหยุด/ดึงกลับบนกรีนเก่ง โซน PANGYA กว้าง | 2 | 4 | 3 | 5 | 3 |
| **Brock** | Power Hitter ตีไกลที่สุด แต่โซน PANGYA แคบ | 5 | 2 | 2 | 3 | 2 |
| **Luna** | Curve Master เลี้ยวลูกอ้อมสิ่งกีดขวางได้มาก | 3 | 3 | 3 | 2 | 5 |
| **Sensei Hiro** | Precision Pro เกจช้า ตีพลาดก็ไม่เสียหายมาก | 2 | 5 | 5 | 3 | 2 |

- **Power** ระยะตีทุกไม้ (ยกเว้นพัตเตอร์) ±4% ต่อแต้ม
- **Control** ความกว้างของโซน PANGYA
- **Accuracy** ความเร็วเกจ และผลเสียเมื่อกด Impact พลาด
- **Spin / Curve** แรงสปินและการเลี้ยวของลูกเมื่อปรับจุดกระทบ

ตัวละครยืนข้างลูก ไม้เงื้อตามเกจพลัง สวิงจริงตอนตี และวิ่งไปดีใจ (หรือเสียใจ) ข้างหลุมเมื่อจบหลุม

## ระบบการเล่นแบบปังย่า

| ระบบ | รายละเอียด |
|---|---|
| **เกจตี 3 จังหวะ** | กด SPACE ครั้งที่ 1 เริ่มสวิง → ครั้งที่ 2 ตั้งแรง → ครั้งที่ 3 ต้องกดให้ตรง **โซน Impact** (แถบสีฟ้า) ถ้าตรงเป๊ะจะขึ้น **"PANGYA!"** |
| **ตีพลาด** | กดเร็วไป ลูกจะเบี้ยวซ้าย (hook) กดช้าไป ลูกจะเบี้ยวขวา (slice) และระยะลดลง |
| **ไม้กอล์ฟ 14 อัน** | 1W–3W, 2I–9I, PW, SW, พัตเตอร์ แต่ละไม้มีระยะ วิถีลูก และสปินต่างกัน |
| **สปิน / เคิร์ฟ** | เลือกจุดกระทบลูก: Topspin = ลูกกลิ้งไกล, Backspin = ลูกหยุดเร็ว/ดึงกลับ, เคิร์ฟซ้าย/ขวา |
| **ลม** | 0–9 m เปลี่ยนทุกช็อต มีผลกับวิถีลูก (ธงบนกรีนจะโบกตามลม) |
| **วงแหวนจุดตก** | วงสีเหลืองแสดงจุดตกที่แรง 100% *แบบไม่มีลม* ต้องคำนวณลมเอง |
| **พื้นที่ตี** | Fairway 100%, Rough 85–95%, Bunker 70% (ใช้ SW ได้ 88%), พื้นเอียงมีผลต่อทิศและมุมลูก |
| **Power Shot** | ตีได้ PANGYA จะได้เกจพลัง (สูงสุด 3 ช่อง) กด E เพื่อใช้ ตีไกลขึ้นแต่โซน Impact แคบลง |
| **ช็อตพิเศษ** | ตอนเปิด Power Shot กด Q เพื่อเลือก **Tomahawk** (ลูกโด่งตกแล้วหยุด), **Spike** (ลูกพุ่งแล้วดิ่ง ไกลที่สุด), **Cobra** (ลูกเรี่ยพื้นแล้วเชิดขึ้น กลิ้งไกล) |
| **กรีน** | มีตารางและจุดไหลบนกรีนแสดงความลาดเอียง (สีฟ้า = เรียบ, เหลือง/แดง = ชัน) |
| **อุปสรรค** | ต้นไม้ (ลูกชนแล้วร่วง), บ่อน้ำ (+1 ลงโทษ), OB (+1 ลงโทษ), ชนเสาธง, ลูกเลียขอบหลุม |
| **คะแนน** | Hole in One, Albatross, Eagle, Birdie, Par, Bogey... และ Chip-in มีสกอร์การ์ดหลังจบแต่ละหลุม |

## กราฟิก

- **Post-processing:** Bloom (แสงฟุ้ง), ACES tone mapping แบบภาพยนตร์, ปรับสีให้สดแบบปังย่า, vignette และแสงวาบตอนตี PANGYA
- **น้ำ:** shader เฉพาะ มีคลื่น สะท้อนท้องฟ้า แสงแดดระยิบ สีน้ำตื้น/ลึก และฟองคลื่นตามขอบฝั่ง
- **สนาม:** ลายตัดหญ้าบนแฟร์เวย์และกรีนแบบสนามจริง, ขอบกรีน (fringe), พื้นผิวมี normal map, หญ้าสูงพลิ้วลมและดอกไม้ป่าในรัฟ
- **ต้นไม้:** ใบไม้ไหวตามลม สีแตกต่างกันทุกต้น มีต้นซากุระ ต้นสน ต้นมะพร้าวรอบบ่อน้ำและกรีน โขดหิน พุ่มดอกไม้ และป่ารอบขอบสนาม
- **ฉากหลัง:** ภูเขามีหิมะบนยอด เนินเขา เมฆนุ่มลอยช้าๆ และฝูงนกบินวน
- **แสง:** แสงแดดอุ่น เงานุ่ม 4 cascade แสงโดยรอบจากท้องฟ้า และ reflection probe แบบ realtime
- **ธงปักหลุม:** ผ้าธงโบกแบบคลื่นจริงตามทิศและแรงลม
- **HUD:** กรอบมุมโค้งไล่สี เกจแบบเงามัน ตัวอักษรมีขอบ และกล้องสั่น/ซูมตอนตีแรง

> ครั้งแรกที่กด Play Unity อาจใช้เวลาคอมไพล์ shader สักครู่

## โครงสร้างโค้ด

```
Assets/PangGolf/
├─ Scripts/
│  ├─ GolfGame.cs      ตัวควบคุมเกมหลัก: ลำดับหลุม เล็ง ตี คะแนน
│  ├─ Characters.cs    ข้อมูลตัวละครและค่าพลัง
│  ├─ CharacterRig.cs  โมเดลตัวละคร 3D + ท่าสวิง/ดีใจ/เสียใจ
│  ├─ ShotGauge.cs     เกจตี 3 จังหวะแบบปังย่า
│  ├─ BallPhysics.cs   ฟิสิกส์ลูก: แรงต้านอากาศ แรงยก สปิน ลม เด้ง กลิ้ง ลงหลุม
│  ├─ Clubs.cs         ข้อมูลไม้กอล์ฟ + คาลิเบรตความเร็วให้ระยะตรงตามเกจ
│  ├─ Course.cs        สร้างสนามแบบ procedural (terrain, แฟร์เวย์, กรีน, บังเกอร์, บ่อน้ำ, ต้นไม้, ธง)
│  ├─ WorldEnv.cs      แสงอาทิตย์ เงา ท้องฟ้า หมอก ภูเขา เมฆ
│  ├─ GreenGrid.cs     ตารางอ่านกรีน
│  ├─ GolfCamera.cs    มุมกล้อง (เล็ง, ตามลูก, จุดตก, กรีน, บินชมหลุม)
│  ├─ GolfHUD.cs       หน้าจอ: เกจ ลม มินิแมพ สปิน ไม้ สกอร์การ์ด
│  ├─ Sfx.cs / Fx.cs   เสียงสังเคราะห์และเอฟเฟกต์อนุภาค
│  ├─ PostFX.cs        Bloom / tone mapping / color grading
│  └─ ...
├─ Resources/         shader: น้ำ, ใบไม้, ภูเขา, post-processing
└─ Editor/PangGolfSetup.cs  ตั้งค่าโปรเจกต์อัตโนมัติ
```

อยากเพิ่มหลุมใหม่ ให้เพิ่ม `HoleDef` ใน `Holes.All` ในไฟล์ `Course.cs` (หน้าสกอร์การ์ดปรับขนาดตามจำนวนหลุมเอง) (กำหนดเส้นทางแฟร์เวย์ กรีน บังเกอร์ บ่อน้ำ ความชันได้)
