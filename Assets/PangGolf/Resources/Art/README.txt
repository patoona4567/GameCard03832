PangGolf - optional art
=======================

Models  -> Assets/PangGolf/Resources/Art/Models/   (FBX / OBJ, any sub-folders)
           Sorted automatically by file name:
             palm                         -> palm trees
             pine, fir, spruce, conifer   -> pine trees
             tree, oak, birch, maple ...  -> broadleaf trees
             bush, shrub, plant, fern     -> bushes
             rock, stone, boulder         -> rocks
             flower, tulip, daisy         -> flowers
           (names containing dead, log, stump, mushroom, grass, path, fence are ignored)
           Or use the folders Art/Trees, Art/Pines, Art/Palms, Art/Bushes, Art/Rocks, Art/Flowers.

Terrain -> Assets/PangGolf/Resources/Art/Terrain/
           Fairway, Green, Rough, DeepRough, Fringe, DryGrass, Sand, Dirt
           plus optional normal maps named <Name>_Normal (e.g. Sand_Normal.png)

Anything missing falls back to the built-in procedural version.
